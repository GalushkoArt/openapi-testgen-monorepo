# @openapi-testgen/cli-win32-x64

Native Windows x64 binary for [@openapi-testgen/cli](https://www.npmjs.com/package/@openapi-testgen/cli).

## Installation

This package is automatically installed as an optional dependency when you install `@openapi-testgen/cli` on Windows x64.

For standalone installation:

```bash
npm install -g @openapi-testgen/cli-win32-x64
```

## Requirements

- Windows 10+ (x64)
- Node.js 18+

## Usage

```cmd
openapi-testgen --help
```
